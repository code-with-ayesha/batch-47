# **Dine Market – E-Commerce Web App**

A modern and fully responsive e-commerce web application built using **Next.js, React, TypeScript, and Tailwind CSS**.

🔗 **Live Demo:** https://dine-market-ayeshaijaz.vercel.app/

---

## 🚀 Features

- Fully responsive design  
- Product listing page  
- Product detail page (dynamic routing)  
- Clean UI with Tailwind CSS  
- Reusable components  
- Fast performance using Next.js  
- Modern layout & smooth shopping flow  

---

## 🛠 Tech Stack

| Technology     | Purpose                                   |
|----------------|-------------------------------------------|
| **Next.js**    | Framework for routing & server components |
| **React**      | UI Development Library                    |
| **TypeScript** | Type-safe development                     |
| **Tailwind CSS** | Styling                                 |
| **Vercel**     | Deployment                                |
